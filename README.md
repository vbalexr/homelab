# Homelab

GitOps repo for **MAGI**, a three-node Talos Linux Kubernetes cluster. Flux syncs the cluster from this repo, and secrets are encrypted with SOPS (age).

## What's in it

- **Cluster services:** Cilium (BGP), Longhorn, cert-manager, metrics-server
- **Databases:** PostgreSQL, MariaDB, Valkey
- **Monitoring:** Prometheus stack, Loki, Alloy
- **DNS:** Technitium
- **Home:** Home Assistant, ESPHome, Zigbee2MQTT, Mosquitto
- **Shared apps:** Immich, Frigate
- **Game servers:** Minecraft
- **Other apps:** sspti, chilu, mrakaki, Tailscale, tunnels
- **Custom images:** `aa-sspti` and `postgres`, built by GitHub Actions

## Structure

```
cluster/magi/          Flux entry point: one Kustomization per layer
  flux-system/         Generated by flux bootstrap, do not edit
  talos/               Talos node configs, image schematic, hardware notes
  GITOPS.md            Flux + SOPS setup
overlays/magi/         What each layer deploys (one folder per layer or app group)
  infrastructure/      Cilium, Longhorn, cert-manager, metrics-server
  configurations/      cert-manager issuers
  database/            postgres, mariadb, valkey
  monitoring/          Prometheus, Loki, Alloy
  dns/ home/ shared/ gameservers/ ...   application groups
containers/            Dockerfiles for custom images
network/               Network and BGP routing design
.github/workflows/     Image builds, update checks, secret scan
.hooks/ .sops.yaml     Block plaintext secrets, SOPS encryption rules
```

Apply order: `infrastructure` → `configurations` → `databases` → application groups.
