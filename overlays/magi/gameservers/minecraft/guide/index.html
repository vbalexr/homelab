Join from Java Edition

Vanilla Minecraft 26.3 can join without any mods. For better FPS and voice chat, use the mod setup below.

  1. Open Minecraft and go to Multiplayer → Add Server.
  2. Server address: minecraft.vbalex.com (25565 is the default port, so you don't need to type it).
  3. Click Done, then Join Server.

How to install it

  1. Install the Modrinth App and sign in with your Microsoft account.
  2. Download the pack with the button above.
  3. In the Modrinth App, click + (Create instance), then Import from file, and pick the .mrpack file. You can also drag the file onto the app window.
  4. Wait for the mods to download, click Play, then go to Multiplayer. The VaCe Server is already on your list.

Prism Launcher can also import the pack: Add Instance → Import and select the file.

Pick the mods yourself in the Modrinth App. It downloads each one and keeps it up to date.

  1. Install the Modrinth App and sign in with your Microsoft account.
  2. Click + (Create instance). Choose loader Fabric and game version 26.3.

Use the official Minecraft Launcher and copy the mod files in yourself.

  1. Run the official launcher once with version 26.3, then close it.
  2. Download the Fabric installer, run it, choose Client and Minecraft version 26.3, and click Install.
  3. For each mod in the table below, open its page, go to Versions, filter by Fabric and 26.3, and download the .jar file.
  4. Put all the .jar files into your mods folder (create it if it doesn't exist):

Using voice chat

  • Press V in game to open the voice chat menu, where you pick your microphone and push-to-talk or voice activation.
  • The default push-to-talk key is Caps Lock. You can change it under Options → Controls.
  • Players hear you only when they are close to you in the game. In the same menu you can create groups for talking at any distance.
  • If the menu says voice chat is not connected, check that your firewall allows UDP traffic to port 24454.

Join from Bedrock Edition (phone, console, Windows)

  1. Go to Play → Servers → Add Server.
  2. Server address: minecraft.vbalex.com, port: 19132.
  3. Save and join. Your name in the game will start with a dot, like .YourName.
Voice chat and Java mods don't work on Bedrock. Everything else, including building, chat and survival, works the same.

Server rules and info

  • Survival in peaceful mode: no hostile mobs, and your health and hunger refill.
